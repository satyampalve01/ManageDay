# ManageDay — Smart Expense & Budget Analyzer

ManageDay is a personal finance web application designed to help users track daily expenses, manage budgets, and understand their spending habits.

## Project Goal

The goal of ManageDay is to make everyday expense tracking and budget management simple through a clean and user-friendly interface.

## Current Features

* Responsive landing page
* Main navigation
* Feature overview
* Basic project introduction

## Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript

## Planned Features

* Add, edit, and delete transactions
* Income and expense summaries
* LocalStorage-based data persistence
* Monthly budget tracking
* Expense analytics and charts
* Spending insights
* CSV export

## Getting Started

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser or use the Live Server extension.

Currently under development.
